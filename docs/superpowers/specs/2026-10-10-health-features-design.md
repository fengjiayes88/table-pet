# V1.3 健康关怀版 设计规格

日期：2026-10-10 ｜ 状态：待用户审查 ｜ 对应版本：V1.3

## 1. 背景与目标

V1.0/V1.1 已全部落地。本期围绕 PRD 核心价值「健康关怀」深化，把单一定时提醒扩展为一套健康关怀体系：

1. **多类型提醒**：喝水提醒、眼保健操提醒（复用现有 Reminder 调度器 + 气泡，不新增美术资源）
2. **番茄钟模式**：工作/休息交替计时，开启期间自动暂停久坐提醒（番茄钟优先，避免双提醒打架）
3. **健康统计**：起身、番茄、喝水、眼操四类打卡事件按日记录
4. **统计展示**：设置页「健康」区块（实时刷新）+ 托盘菜单「今日统计」气泡快照

成功标准：所有新功能在现有设置页/托盘/气泡交互模式内完成，无新窗口类型、无新美术资源；`npm run check` 全绿。

## 2. 已确认的产品决策

| 决策点 | 结论 |
|---|---|
| 番茄钟与久坐提醒冲突 | 番茄钟开启期间久坐提醒暂停，关闭后恢复（重新计时）；喝水/眼操不受影响 |
| 统计展示 | 设置页健康区块 + 托盘「今日统计」气泡，两者都要 |
| 喝水/眼操默认状态 | 默认关闭，用户按需开启 |
| 番茄钟默认状态 | 默认关闭，时长默认 25/5 分钟，可配置 |
| 打卡判定 | 双击七七解除对应提醒 = 打卡一次；番茄每完成一个工作段计 1 次 |
| 气泡互斥 | 同一时刻只显示一个气泡；被占用时新到点的提醒跳过本轮并重新计时 |

## 3. 功能规格

### 3.1 多类型提醒

- Reminder 类实例化为 3 份：久坐（现有，type=`sedentary`）、喝水（type=`drink`）、眼操（type=`eye`）
- 各自独立的开关 + 间隔（分钟）设置项
- 气泡文案：喝水 `该喝水啦～双击七七打卡！`；眼操 `眼睛也需要休息，做个眼保健操吧～双击七七打卡！`
- 触发时宠物进入现有 REMINDER 动画（复用提醒精灵图）

### 3.2 番茄钟

- 设置项：开关（默认关）、工作时长（默认 25，5–120 分钟）、休息时长（默认 5，1–60 分钟）
- 工作段结束：气泡 `番茄完成！休息 N 分钟吧～` + 宠物提醒动画，自动进入休息段
- 休息段结束：气泡 `休息结束，继续加油！`，自动进入下一个工作段
- 循环持续到用户关闭番茄钟；每完成一个工作段记 1 次番茄打卡
- 修改时长设置：立即用新时长重启当前阶段

### 3.3 健康统计

- 事件类型：`standup`（久坐提醒双击解除）、`pomodoro`（工作段完成）、`drink`（喝水打卡）、`eye`（眼操打卡）
- 存储在 `userData/stats.json`，按本地日期为 key：`{ "2026-10-10": { standup: 3, pomodoro: 2, drink: 1, eye: 0 } }`
- 写入时只保留最近 30 天
- 打卡归属：气泡显示期间双击七七 → 解除当前活跃的那个提醒并记录对应类型；直接点气泡关闭不打卡
- 跨午夜：按打卡时刻的日期记录

### 3.4 统计展示

- 设置页新增「健康」区块（位于「行为」之后）：番茄钟、喝水、眼操设置 + 今日统计行（`起身 N 次 · 番茄 N 个 · 喝水 N 次 · 眼操 N 次`），事件发生时实时刷新
- 托盘菜单新增「今日统计」：点击弹出气泡展示同样的统计文案（纯展示，关闭不产生任何打卡或状态变化）

## 4. 架构设计

沿用现有分层：**渲染进程持计时器，主进程持窗口与持久化，纯逻辑沉到 shared**。

```
渲染进程                              主进程
┌─────────────────────────┐          ┌──────────────────────────┐
│ app.js（接线层）          │          │ main.js                   │
│  ├ Reminder ×3（多实例）  │──IPC──▶ │  ├ stats:event 记录+落盘   │
│  ├ Pomodoro（新类）       │◀─IPC─── │  ├ stats:query 返回今日    │
│  ├ activeReminder 指针    │          │  ├ stats-updated 广播     │
│  └ 打卡时上报事件          │          │  └ 托盘「今日统计」→气泡复用 │
└─────────────────────────┘          └──────────────────────────┘
        │                                      │
        ▼                                      ▼
  shared/app-logic.js（纯逻辑+测试）      userData/stats.json
```

- **Reminder 类**：构造参数增加 `type`、`message`；`showBubble` 被拒（气泡已被占用）时自动重启本轮计时。计时器注入式（`setIntervalFn/nowFn` 可替换）以便测试
- **Pomodoro 类（新文件 `src/renderer/pomodoro.js`）**：工作/休息交替倒计时，回调 `onPhaseComplete(phase)`，同样注入式计时器
- **app.js**：持有 `activeReminder` 指针（触发时设置、解除时清空）解决打卡归属；番茄钟开关切换时协调久坐提醒的启停
- **主进程 stats 存储**：读失败/文件损坏时返回零值不崩；每次事件同步落盘（事件频率低，无需防抖）
- **preload**：新增 `statsEvent(type)`、`statsQuery()`、`onStatsUpdated(cb)`

## 5. 设置 schema 变更

`normalizeSettings` 新增字段（含校验规则）：

| 字段 | 类型 | 默认 | 校验 |
|---|---|---|---|
| pomodoroEnabled | boolean | false | — |
| pomodoroWork | number | 25 | 整数，clamp 5–120 |
| pomodoroBreak | number | 5 | 整数，clamp 1–60 |
| drinkReminderEnabled | boolean | false | — |
| drinkReminderInterval | number | 60 | 整数，clamp 5–999 |
| eyeReminderEnabled | boolean | false | — |
| eyeReminderInterval | number | 45 | 整数，clamp 5–999 |

旧 settings.json 无这些字段 → 走默认值（`normalizeSettings` 现有机制天然兼容）。

## 6. 测试策略

- `test/app-logic.test.js` 扩展：新设置字段校验（含越界 clamp）、统计纯函数（记录/读取/30 天裁剪/跨午夜）
- `test/pomodoro.test.js` 新建：阶段交替、时长变更重启、开关启停（注入式计时器，测试秒级完成）
- `test/reminder-multi.test.js` 新建：多实例互不干扰、气泡被拒后重启计时、打卡归属由 app.js 指针保证（指针逻辑以冒烟路径覆盖）
- 主进程 IPC 与托盘菜单：`npm run check:syntax` + 冒烟脚本 + 最终人工 QA 清单

## 7. 风险

| 风险 | 应对 |
|---|---|
| 多提醒同时到点轰炸 | 气泡互斥 + 跳过本轮重启，绝不排队连弹 |
| stats.json 损坏 | 读失败返回零值，下次写入自动修复 |
| 番茄钟开关快速切换状态错乱 | 协调逻辑收敛在 app.js 单点，启停都是幂等操作 |
| 旧版本升级用户 | 新字段全有默认值，行为与 V1.2 完全一致（新开关默认关） |
